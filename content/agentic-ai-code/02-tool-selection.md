# Tool selection

## Why it matters
AI coding assistants work best when they choose the right tool for the job. Picking a broad editor command, a targeted search, or a small test run changes the quality and cost of the workflow.

## Better patterns
- Search first for the exact symbol or file.
- Read only the relevant sections before editing.
- Run the smallest test or validation command that checks the change.
- Prefer direct edits over broad rewrites.

## Real project example
An agent looking for a routing issue starts with the route configuration and the page component, not with the whole project. Once the bug is isolated, it makes a small fix and validates the affected path.

> **Pro tip:** the best assistant is not the one with the most actions; it is the one with the most precise ones.
