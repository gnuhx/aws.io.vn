7.14

AWS Amplify and AppSync

Amplify là bộ framework + CLI + hosting dựng nhanh app web/mobile full-stack. AppSync là dịch vụ GraphQL managed, hỗ trợ real-time subscriptions và offline sync. Ví dụ: Amplify như bộ đồ nghề lắp nhà lắp ghép nhanh cho developer front-end; AppSync là "tổng đài GraphQL" trả lời đúng câu khách hỏi thay vì trả nguyên cả kho REST.

  • Amplify Hosting: CI/CD tự động deploy từ Git
  • Amplify Libraries: SDK client kết nối Cognito/AppSync/S3
  • AppSync: GraphQL managed, resolver nối trực tiếp DynamoDB/Lambda/RDS

Pattern nâng cao / case thực tế

Dùng Direct Resolver của AppSync gọi thẳng DynamoDB, bỏ qua Lambda để giảm latency.

Case: startup mobile game cần bảng leaderboard realtime cho hàng nghìn người chơi. Dùng AppSync subscription push update ngay khi có điểm mới, thay vì polling liên tục gây tốn tài nguyên.
🏭 Vị trí kiến trúc: Gắn cạnh Sảnh phân luồng — API Gateway, là "quầy tiếp tân nhanh cho web/mobile" song song API Gateway, nối vào Xưởng lắp ráp Lambda và Kho tổng DynamoDB.

7.15

AWS Device Farm

Dịch vụ test ứng dụng mobile/web trên thiết bị thật trong cloud, không cần mua hàng trăm điện thoại thật. Ví dụ: phòng lab QA ảo có sẵn hàng trăm điện thoại thật, thuê theo giờ thay vì mua đứt.

  • Automated testing: chạy test suite (Appium, Espresso, XCTest) song song nhiều thiết bị
  • Remote access: điều khiển trực tiếp 1 thiết bị qua browser để debug thủ công

Pattern nâng cao / case thực tế

Tích hợp vào CodePipeline/CodeBuild để tự động test mỗi lần có build mới, chặn merge nếu fail.

Case: app fintech mobile banking cần đúng trên 50+ dòng máy Android trước mỗi release, vì lỗi hiển thị sai số dư có thể gây khiếu nại nghiêm trọng. Tự động hóa test suite qua Device Farm trong CI/CD thay vì test thủ công nhiều ngày.
🏭 Vị trí kiến trúc: Đứng ngoài luồng production — "phòng QA kiểm định trước khi xuất xưởng", không phục vụ request khách hàng thật.

  --device-pool-arn arn:...:devicepool:zzz \
  --test '{"type":"APPIUM_JAVA_TESTNG"}'

AWS Machine Learning and AI Services

Nhóm dịch vụ AI/ML managed, pre-trained — gọi API dùng ngay, không cần tự train model. Ví dụ: thuê chuyên gia bên ngoài xử lý việc chuyên môn (ảnh, dịch thuật, giọng nói) thay vì tự đào tạo nhân viên nội bộ.

  • Rekognition: ảnh/video · Comprehend: NLP text · Transcribe: speech-to-text
  • Polly: text-to-speech · Translate: dịch ngôn ngữ · Lex: chatbot
  • Textract: OCR document · SageMaker: build/train model custom

Pattern nâng cao / case thực tế

Kết hợp S3 event → Lambda → Rekognition để tự động xử lý ngay khi có ảnh mới upload.

Case: sàn TMĐT nhận hàng triệu ảnh sản phẩm mỗi ngày. Dùng Rekognition tự động detect nội dung không phù hợp ngay khi upload, chặn hiển thị công khai trước khi kiểm duyệt thủ công.
🏭 Vị trí kiến trúc: Nhóm "phòng ban chuyên gia thuê ngoài" gắn cạnh Xưởng lắp ráp Lambda/EC2 — xử lý tác vụ chuyên biệt rồi trả kết quả về, không phải trạm sản xuất chính.

Lệnh quan trọng

aws rekognition detect-labels \
  --image '{"S3Object":{"Bucket":"my-bucket","Name":"photo.jpg"}}'

aws comprehend detect-sentiment \
  --text "Sản phẩm này rất tốt" --language-code vi

aws transcribe start-transcription-job \
  --transcription-job-name job1 \
  --media MediaFileUri=s3://my-bucket/audio.mp3 \
  --language-code vi-VN

aws textract analyze-document \
  --document '{"S3Object":{"Bucket":"my-bucket","Name":"form.png"}}' \
  --feature-types '["FORMS"]'
FlagViết tắtÝ nghĩa
--imageImage SourceVị trí ảnh S3 để Rekognition phân tích
--language-codeLanguage CodeMã ngôn ngữ xử lý
--mediaMedia SourceFile audio/video nguồn cho Transcribe

7.18

AWS License Manager

Quản lý tập trung license phần mềm BYOL (Bring Your Own License) khi chạy trên AWS, tránh vi phạm điều khoản (Windows Server, SQL Server, Oracle...). Ví dụ: sổ theo dõi giấy phép sử dụng thiết bị trong công ty, cảnh báo khi vượt số lượng đã mua.

  • Theo dõi theo core, socket, hoặc instance
  • Rules ngăn launch instance mới vi phạm license

Pattern nâng cao / case thực tế

Tích hợp với AWS Organizations để enforce license tập trung toàn bộ account trong tổ chức.

Case: tập đoàn có nhiều team tự launch Windows/SQL Server rải rác nhiều account. Triển khai License Manager cấp Organization để theo dõi tập trung, tránh bị phạt khi Microsoft audit.
🏭 Vị trí kiến trúc: Thuộc "lớp phủ toàn nhà máy" như IAM/KMS — "sổ theo dõi giấy phép thiết bị" áp lên toàn bộ Xưởng lắp ráp EC2.

Lệnh quan trọng

aws license-manager create-license-configuration \
  --name "SQLServer-Standard" \
  --license-counting-type vCPU \
  --license-count 100 \
  --license-count-hard-limit

aws license-manager list-usage-for-license-configuration \
  --license-configuration-arn arn:...:license-configuration:xxx
FlagViết tắtÝ nghĩa
--license-counting-typeCounting TypeĐơn vị đếm (vCPU, Core, Socket, Instance)
--license-countLicense CountTổng số license được phép
--license-count-hard-limitHard LimitChặn cứng khi vượt, không chỉ cảnh báo

AWS Compute Optimizer

Dùng Machine Learning phân tích lịch sử sử dụng CPU/RAM/network của EC2, EBS, Lambda, ASG để đề xuất right-sizing. Ví dụ: chuyên gia phân tích hóa đơn điện nước hàng tháng, đề xuất gói phù hợp hơn với thói quen sử dụng thực tế.

Pattern nâng cao / case thực tế

Bật Enhanced infrastructure metrics để phân tích dựa trên 3 tháng dữ liệu thay vì 14 ngày mặc định.

Case: công ty game có traffic tăng vọt dịp lễ Tết. 14 ngày mặc định (rơi vào thấp điểm) có thể khiến Compute Optimizer đề xuất downsize nhầm — bật Enhanced metrics để thấy toàn bộ chu kỳ traffic.
🏭 Vị trí kiến trúc: Thuộc nhóm lớp phủ giám sát như CloudWatch — "phòng kế toán kỹ thuật" theo dõi hiệu suất Xưởng lắp ráp EC2/ASG/Lambda.

Lệnh quan trọng

aws compute-optimizer get-ec2-instance-recommendations \
  --instance-arns arn:aws:ec2:...:instance/i-0123456789

aws compute-optimizer get-auto-scaling-group-recommendations \
  --auto-scaling-group-arns arn:...:autoScalingGroup:xxx
FlagViết tắtÝ nghĩa
--instance-arnsInstance ARNsEC2 instance cần đề xuất right-sizing
--auto-scaling-group-arnsASG ARNsAuto Scaling Group cần đề xuất tối ưu

7.23

AWS Cost Management Tools

Bộ công cụ theo dõi & tối ưu chi phí: Budgets (ngưỡng cảnh báo), Cost Explorer (phân tích & dự báo), CUR (báo cáo chi tiết ra S3), Cost Allocation Tags (phân bổ theo team/project), Savings Plans/RI, Trusted Advisor. Ví dụ: phòng kế toán công ty có nhiều công cụ khác nhau — 1 cái cảnh báo vượt ngân sách, 1 cái vẽ biểu đồ chi tiêu, 1 cái báo cáo theo phòng ban.

Pattern nâng cao / case thực tế

Dùng Budget Actions để tự động áp SCP/IAM policy khi vượt ngưỡng, thay vì chỉ gửi email.

Case: startup ngân sách hạn chế thiết lập Budget Action tự động áp SCP chặn launch EC2 mới khi chi phí tháng chạm 90% ngân sách, tránh "cháy túi" ngoài kiểm soát.
🏭 Vị trí kiến trúc: Nhóm "phòng kế toán trung tâm" — lớp phủ tài chính áp lên tất cả các trạm trong nhà máy, không phải trạm sản xuất.

Lệnh quan trọng

aws budgets create-budget \
  --account-id 123456789012 \
  --budget file://budget.json \
  --notifications-with-subscribers file://notifications.json

aws ce get-cost-and-usage \
  --time-period Start=2026-01-01,End=2026-02-01 \
  --granularity MONTHLY --metrics "UnblendedCost" \
  --group-by Type=TAG,Key=Project

aws ce get-rightsizing-recommendation --service AmazonEC2
FlagViết tắtÝ nghĩa
--budgetBudget DefinitionJSON định nghĩa ngân sách
--granularityGranularityĐộ chi tiết theo thời gian
--group-byGroup ByNhóm chi phí theo tiêu chí (vd tag)

Cấu hình liên quan

Cost Allocation Tag cần Activate thủ công trong Billing console — tag đã gắn resource nhưng chưa activate sẽ không lên report.

🧭 Bối cảnh

Bạn được giao 2 việc trong tuần đầu: (1) dựng 1 pipeline tự động xử lý video khách hàng upload bằng Rekognition, và (2) thiết lập bộ theo dõi chi phí đầy đủ (Budget + Cost Explorer + Cost Allocation Tags) — vì sếp vừa bị "sốc hóa đơn" AWS tháng trước.

aws rekognition get-label-detection --job-id <job-id>

aws lambda delete-function --function-name process-video
aws s3 rb s3://video-pipeline-lab --force

⚠️ Lưu ý dễ tốn phí

  • Cost Allocation Tag không tự lên report nếu quên bước "Activate" thủ công — lỗi hay bị bỏ sót nhất.
  • Cost Explorer có độ trễ ~24h — đừng hoảng nếu vừa gắn tag mà chưa thấy số liệu ngay.
  • Rekognition Video là async — phải poll get-label-detection hoặc nhận qua SNS.
  • Budget Action tự động (SCP) cần cấu hình cẩn thận, tránh chặn nhầm resource production.
# Bước 1 — Pipeline xử lý video tự động (Rekognition)
aws s3 mb s3://video-pipeline-lab

aws lambda create-function \
  --function-name process-video \
  --runtime python3.12 --handler app.handler \
  --role arn:aws:iam::...:role/VideoPipelineRole \
  --zip-file fileb://function.zip

aws s3api put-bucket-notification-configuration \
  --bucket video-pipeline-lab \
  --notification-configuration file://notif-config.json

aws rekognition start-label-detection \
  --video '{"S3Object":{"Bucket":"video-pipeline-lab","Name":"sample.mp4"}}' \
  --notification-channel RoleArn=arn:aws:iam::...:role/RekognitionSNSRole,SNSTopicArn=arn:aws:sns:...:video-results

# Bước 2 — Cost Allocation Tags
aws s3api put-bucket-tagging --bucket video-pipeline-lab \
  --tagging 'TagSet=[{Key=Project,Value=VideoPipeline}]'
aws lambda tag-resource --resource arn:aws:lambda:...:function:process-video \
  --tags Project=VideoPipeline
# Activate tag "Project" trong Billing console (chỉ làm được qua UI)

aws ce get-rightsizing-recommendation --service AmazonEC2

aws support describe-trusted-advisor-checks --language en \

Pattern chuẩn cần nhớ nằm lòng

S3 upload → Lambda trigger → AI Service (Rekognition/Textract/Comprehend) xử lý → lưu kết quả/SNS thông báo. Theo dõi chi phí chuẩn: Cost Allocation Tags (activate) → Cost Explorer (phân tích xu hướng) → AWS Budgets (cảnh báo/action) → CUR (chi tiết sâu qua Athena nếu cần). Web/mobile app nhanh: Amplify (frontend + hosting) → AppSync (GraphQL) → DynamoDB/Lambda → Cognito (auth).

  • Quầy tiếp tân nhanh cho web/mobile — Amplify + AppSync, song song API Gateway
  • Phòng QA kiểm định trước khi xuất xưởng — Device Farm, ngoài luồng production
  • Phòng ban chuyên gia thuê ngoài — Rekognition, Comprehend, Transcribe, Polly, Translate, Lex, Textract, SageMaker
  • Sổ theo dõi giấy phép thiết bị — License Manager, lớp phủ toàn Xưởng lắp ráp EC2
  • Phòng kế toán kỹ thuật — Compute Optimizer, lớp phủ giám sát hiệu suất
