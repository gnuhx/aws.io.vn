🏭 Trạm mới thêm vào nhà máy nền ở Module 7 (section cuối cùng)

  • Phòng kế hoạch mở rộng — Migration Hub + Application Discovery Service + Strategy Recommendations (7 Rs), đứng tách biệt quan sát toàn bộ bản đồ.
  • Đội bốc dỡ hàng chuyên trách tạm thời — AWS DMS, giữa database cũ và Kho tổng RDS/Aurora.
  • Đội dựng nhà y hệt bản gốc — AWS MGN, đưa nguyên khối server cũ vào Xưởng lắp ráp EC2.
  • Băng chuyền chạy định kỳ — AWS DataSync, nối kho cũ-mới quanh khu Kho hàng tĩnh S3/EFS/FSx.
  • Cửa nhận hàng hóa vật lý — AWS Snow Family, cổng riêng ngoài network layer thông thường.
  • Quầy tiếp tân nhanh cho web/mobile — Amplify + AppSync, song song ALB/API Gateway.
  • Phòng QA kiểm định trước khi xuất xưởng — AWS Device Farm, ngoài luồng production.
  • Phòng ban chuyên gia thuê ngoài — Rekognition, Comprehend, Transcribe, Polly, Translate, Lex, Textract, SageMaker.
  • Sổ theo dõi giấy phép thiết bị — AWS License Manager, lớp phủ toàn Xưởng lắp ráp EC2.
  • Phòng kế toán trung tâm + kỹ thuật — Compute Optimizer, AWS Budgets, Cost Explorer, CUR, Cost Allocation Tags.
