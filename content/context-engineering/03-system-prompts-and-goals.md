# System prompts and goals

## Why it matters
When you give an AI a clear role, constraints, and objective, it produces more consistent output. A good prompt is not just about style; it is about decision quality.

## Strong structure
- Define the role clearly.
- State the end goal.
- Mention the key constraints.
- Specify the expected output format.

## Real project example
Instead of asking, “Fix this,” a teammate asks the agent to repair a broken route while preserving existing navigation and testing the affected route. The result is narrower, safer, and easier to review.

> **Pro tip:** explicit constraints reduce improvisation and improve reproducibility.
