🎯 Khái niệm

Lesson 3.7 không đưa ra khái niệm mới, mà là bài "ráp toàn bộ dàn nhạc lại với nhau" — kết hợp State + Nodes + Edges + Compile + Run thành một workflow hoàn chỉnh, đồng thời học cách trace từng bước và bọc theo production pattern.

Ví dụ đời sống

Một dây chuyền sản xuất bánh mì: State = phiếu đặt hàng · Node = từng công nhân (nhào bột / nướng / đóng gói) · Edge = băng chuyền nối các bàn · Compile = quy trình đã setup xong, chạy lại mỗi ngày · app.stream() = quản lý đứng ghi chép từng công đoạn real-time · try/except = nhân viên giám sát báo động ngay khi có công đoạn hỏng.

⌨️ Các lệnh quan trọng

from typing import TypedDict, List
from langgraph.graph import StateGraph, START, END

# 1) Định nghĩa STATE
class MyState(TypedDict):
    field_a: str

# 2) Tạo graph
graph = StateGraph(MyState)

# 3) Thêm node — fn(state) -> dict
graph.add_node("node_name", node_function)

# 4) Nối edge
graph.add_edge(START, "node_name")
graph.add_edge("node_name", END)

# 5) Compile
app = graph.compile()

# 6) Run
app.invoke(initial_state)      # state cuối cùng
app.stream(initial_state)      # trace từng bước
Lệnh / flagÝ nghĩa
StateGraph(Type)Khởi tạo graph builder theo schema TypedDict
add_node(name, fn)fn nhận state, return dict field cần update — không cần trả toàn bộ state
add_edge(from, to)Cạnh cố định (unconditional), luôn đi từ → to
START / ENDNode đặc biệt built-in đánh dấu điểm vào/ra
.compile()Trả về app — sau bước này cấu trúc graph immutable
.invoke(state)Chạy 1 lượt, trả state cuối cùng
.stream(state)Generator, yield {node: update} sau mỗi node — dùng để trace
.ainvoke()/.astream()Bản async — dùng trong FastAPI để không block event loop

Production pattern nâng cao

import logging
logger = logging.getLogger("workflow")

try:
    for step in app.stream(initial_state):
        node_name = list(step.keys())[0]
        logger.info(f"Node '{node_name}' done: {step[node_name]}")
except Exception as e:
    logger.error(f"Workflow failed: {e}")
    raise

logging có level/timestamp/ghi file thay vì print(); try/except bọc quanh run để bắt lỗi rõ ràng thay vì crash im lặng.

⚡ Cheat Sheet nhanh

from langgraph.graph import StateGraph, START, END

class MyState(TypedDict): ...      # 1. state
graph = StateGraph(MyState)             # 2. tạo graph
graph.add_node("name", fn)              # 3. thêm node
graph.add_edge(START, "name")           # 4. nối edge
graph.add_edge("name", END)
app = graph.compile()                   # 5. compile
app.invoke(state)                       # 6a. chạy 1 lần
for step in app.stream(state): ...      # 6b. trace

📌 5 khối kiến trúc

  • State — TypedDict, dữ liệu xuyên graph
  • Node — fn(state) → dict update
  • Edge — thứ tự chạy cố định
  • Compile — build app, immutable
  • Run — invoke (1 lần) / stream (trace)

🧪 Lab steps tóm tắt

  1. Setup venv, pip install langgraph
  2. Viết ReportState + 4 node
  3. Nối edge tuần tự validate→research→draft→review
  4. Compile app
  5. Chạy app.stream(), verify log đúng thứ tự

⚠️ Dễ sai / dễ "brick"

  • Quên nối START/END
  • Node không return dict → field không update (silent bug)
  • Sửa graph sau khi đã .compile()
  • Không bọc try/except quanh run
  • Nhầm .invoke() (dict) với .stream() (generator)

✅ Lệnh verify

  • Trace in đúng 4 dòng theo thứ tự node
  • Output cuối chứa [Đã qua review]
  • Đổi topic ngắn ≤3 ký tự → thấy điểm mù (chưa conditional edge)

🍡 Story Mode — Tanjiro & Full LangGraph Workflow

Tanjiro nhận nhiệm vụ diệt quỷ ở làng Rừng Trúc. Toàn bộ quy trình nhiệm vụ ánh xạ 1-1 với LangGraph workflow của Lesson 3.7:

Khái niệm gốcChi tiết trong truyện
StateCuốn nhật ký nhiệm vụ (NhiemVuState) — ghi tên làng, dấu vết, báo cáo, trạng thái duyệt
Nodedanh_hoi_node (đánh hơi), thu_thap_dau_vet_node (dò vết), viet_bao_cao_node (viết báo cáo), giko_kiem_tra_node (Giko duyệt)
EdgeCon đường cố định: đánh hơi → dò vết → viết báo cáo → Giko duyệt
CompileTanjiro đã "thuộc lòng" quy trình, dùng lại được cho làng khác
app.stream()Zenitsu đi theo, ghi chép từng bước theo thời gian thực
try/exceptBùa hộ mệnh của Giko — nếu sự cố, không "vỡ trận" mà báo lỗi rõ ràng
🐛 Bug hài hước: Inosuke từng nhảy vào đòi đánh quỷ ngay, bỏ qua bước "đánh hơi" — đây chính là lỗi sai thứ tự edge. Vì edge danh_hoi → thu_thap_dau_vet đã cố định, Inosuke không thể chen ngang, y hệt LangGraph không cho nhảy cóc qua edge chưa định nghĩa.

💻 Code thật (production-style, đã chạy kiểm chứng)

from typing import TypedDict, List
import logging

logging.basicConfig(level=logging.INFO, format="[%(levelname)s] %(message)s")
logger = logging.getLogger("kimetsu_workflow")

from langgraph.graph import StateGraph, START, END


class NhiemVuState(TypedDict):
    ten_lang: str
    da_xac_nhan_co_quy: bool
    dau_vet_nguoi_hit: List[str]
    ban_bao_cao_chien_dau: str
    da_qua_kiem_tra_Giko: bool
    bao_cao_cuoi_cung: str


def danh_hoi_node(state: NhiemVuState) -> dict:
    logger.info(f"[danh_hoi_node] Tanjiro đánh hơi ở làng {state['ten_lang']!r}")
    try:
        co_quy = len(state["ten_lang"].strip()) > 3
        return {"da_xac_nhan_co_quy": co_quy}
    except Exception as e:
        logger.error(f"Tanjiro đánh hơi lỗi (có thể do cảm cúm): {e}")
        return {"da_xac_nhan_co_quy": False}


def thu_thap_dau_vet_node(state: NhiemVuState) -> dict:
    logger.info("[thu_thap_dau_vet_node] Tanjiro dò dấu vết quanh làng")
    dau_vet = [
        f"Làng {state['ten_lang']} có mùi máu quỷ ở giếng nước",
        f"Dân làng {state['ten_lang']} kể có tiếng gầm lúc nửa đêm",
    ]
    return {"dau_vet_nguoi_hit": dau_vet}


def viet_bao_cao_node(state: NhiemVuState) -> dict:
    logger.info("[viet_bao_cao_node] Tanjiro tổng hợp dấu vết thành báo cáo")
    bao_cao = f"BÁO CÁO NHIỆM VỤ TẠI {state['ten_lang'].upper()}\n" + "\n".join(
        f"- {d}" for d in state["dau_vet_nguoi_hit"]
    )
    return {"ban_bao_cao_chien_dau": bao_cao}


def giko_kiem_tra_node(state: NhiemVuState) -> dict:
    logger.info("[giko_kiem_tra_node] Giko kiểm tra báo cáo của Tanjiro")
    dat = len(state["ban_bao_cao_chien_dau"]) > 20
    bao_cao_cuoi = (
        state["ban_bao_cao_chien_dau"] + "\n\n[Giko đã duyệt - nhiệm vụ hoàn thành]"
        if dat else state["ban_bao_cao_chien_dau"]
    )
    return {"da_qua_kiem_tra_Giko": dat, "bao_cao_cuoi_cung": bao_cao_cuoi}


graph = StateGraph(NhiemVuState)
graph.add_node("danh_hoi", danh_hoi_node)
graph.add_node("thu_thap_dau_vet", thu_thap_dau_vet_node)
graph.add_node("viet_bao_cao", viet_bao_cao_node)
graph.add_node("giko_kiem_tra", giko_kiem_tra_node)

graph.add_edge(START, "danh_hoi")
graph.add_edge("danh_hoi", "thu_thap_dau_vet")
graph.add_edge("thu_thap_dau_vet", "viet_bao_cao")
graph.add_edge("viet_bao_cao", "giko_kiem_tra")
graph.add_edge("giko_kiem_tra", END)

app = graph.compile()

if __name__ == "__main__":
    nhiem_vu_dau = {
        "ten_lang": "Rừng Trúc", "da_xac_nhan_co_quy": False,
        "dau_vet_nguoi_hit": [], "ban_bao_cao_chien_dau": "",
        "da_qua_kiem_tra_Giko": False, "bao_cao_cuoi_cung": "",
    }
    for step in app.stream(nhiem_vu_dau):
        ten_node = list(step.keys())[0]
        print(f"--> Tanjiro vừa xong bước '{ten_node}'. Nhật ký: {step[ten_node]}")

🔑 Tại sao code này chạy được

Đây không phải phép màu của "chủ đề Kimetsu" — LangGraph hoàn toàn không quan tâm state tên là NhiemVuState hay field tên ten_lang. Framework chỉ cần 3 điều: (1) state là TypedDict hợp lệ, (2) node là hàm nhận state trả về dict, (3) edge định nghĩa đúng thứ tự chạy — bất kể node tên là "đánh hơi" hay "validate". Đổi toàn bộ tên biến/hàm sang chủ đề Kimetsu nhưng cấu trúc State/Node/Edge/Compile/Run giữ nguyên 100%, nên code chạy y hệt bản gốc. Nắm đúng 5 khối kiến trúc này, bạn áp dụng được cho bất kỳ domain nào — chatbot, report pipeline, hay nhiệm vụ diệt quỷ.
