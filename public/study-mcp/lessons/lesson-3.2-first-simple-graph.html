1.1Khái niệm & Ví dụ đời sống

Biến 3 pillars (State/Node/Edge) từ Lesson 3.1 thành code chạy được, qua 5 bước cố định.

ANALOGY Tưởng tượng một dây chuyền sản xuất bánh mì: State là cái khay/phiếu công việc đi theo ổ bánh qua từng trạm. Node là từng trạm xử lý (nhào bột → nướng → đóng gói), mỗi trạm cập nhật lại phiếu. Edge là băng chuyền nối các trạm theo đúng thứ tự. Compile là bước kiểm tra & lắp ráp toàn bộ dây chuyền. Invoke là bấm nút chạy với 1 mẻ bột cụ thể — và vì đã lắp ráp (compile) xong, bạn chạy được nhiều mẻ (invoke nhiều lần) mà không cần dựng lại dây chuyền.

1.4Lệnh quan trọng + code mẫu

// 1. Định nghĩa State 
from typing import TypedDict

class SimpleState(TypedDict):
    input_text: str
    step_a_result: str
    step_b_result: str
    final_output: str
// 2. Khởi tạo graph builder 
from langgraph.graph import StateGraph, START, END

graph = StateGraph(SimpleState)
// 3. Thêm node — mỗi node trả về dict (không cần trả cả state) 
def node_a(state: SimpleState) -> dict:
    return {"step_a_result": state["input_text"].upper()}

def node_b(state: SimpleState) -> dict:
    return {"step_b_result": state["step_a_result"] + "!!!"}

def node_c(state: SimpleState) -> dict:
    return {"final_output": f"Done: {state['step_b_result']}"}

graph.add_node("A", node_a)
graph.add_node("B", node_b)
graph.add_node("C", node_c)
// 4. Nối edge + entry/finish point 
graph.add_edge(START, "A")
graph.add_edge("A", "B")
graph.add_edge("B", "C")
graph.add_edge("C", END)

# Cách cũ tương đương:
# graph.set_entry_point("A")
# graph.set_finish_point("C")
// 5. Compile & Invoke 
app = graph.compile()

result = app.invoke({
    "input_text": "hello langgraph",
    "step_a_result": "",
    "step_b_result": "",
    "final_output": "",
})
print(result)

Lab Steps tóm tắt

  2. Tạo file first_graph.py
  3. Định nghĩa SimpleState(TypedDict)
  4. Viết 3 hàm node (A, B, C) — mỗi hàm trả 1 dict field mới
  5. graph = StateGraph(SimpleState) → add_node x3
  6. add_edge(START,"A") → ... → add_edge("C",END)
  7. app = graph.compile()
  8. app.invoke({...}) rồi print(result)
  9. Verify: state cuối có đủ 4 field, đúng giá trị mong đợi
🐛 Lỗi thường gặp: quên field trong initial_state → KeyError; gọi .invoke() trên graph chưa compile thay vì trên app.

05🍡 Story Mode — Tanjiro "phá đảo" StateGraph

Đọc cho vui, nhưng code bên dưới là code thật, chạy được thật — không phải giả lập. Copy nguyên file, chạy python tanjiro_graph.py, ra kết quả y hệt phần "Terminal output" phía dưới.

STORY State (TypedDict) — Tanjiro có một cuốn sổ tay hít thở ghi lại tình trạng bản thân xuyên suốt hành trình: HP còn bao nhiêu, đang dùng hơi thở gì, đã diệt quỷ nào.

StateGraph() — Đây chính là Diệt Quỷ Đoàn (Kisatsutai): tổ chức "khởi tạo" ra toàn bộ khung nhiệm vụ, biết trước Tanjiro sẽ mang theo loại sổ tay nào.

add_node() — Từng trận đánh được thêm vào cây truyện: Final Selection, hạ Rui, chuyến tàu Vô Hạn, Vô Diệt Thành. Mỗi trận là 1 hàm — Tanjiro vào với 1 trạng thái, ra với sổ tay đã đổi khác (thêm quỷ đã hạ, trừ HP).

add_edge() — Con đường truyện nối liền các trận theo đúng thứ tự. (⚠️ Inosuke không đi theo edge nào cả — cứ nhảy xổ vào node bất kỳ, executor phải warning suốt tập.)

compile() — Khoảnh khắc Tanjiro tốt nghiệp Final Selection: cấu trúc hành trình "đóng băng", không quay đầu chọn nghề khác được nữa.

invoke() — Mỗi lần Ubuyashiki giao nhiệm vụ mới là 1 lần gọi app.invoke({...}). Cả bộ truyện là hàng chục lần invoke liên tiếp — lần cuối cùng, final_output trả về: hạ Muzan, Nezuko thành người. 🎉
// tanjiro_graph.py — code thật, chạy bằng: pip install langgraph && python tanjiro_graph.py 
from typing import TypedDict
from langgraph.graph import StateGraph, START, END


# ============================================================
# 1. STATE — cuốn "sổ tay hít thở" Tanjiro mang theo xuyên truyện
# ============================================================
class DemonSlayerState(TypedDict):
    hp: int                  # máu còn lại
    hoi_tho: str              # loại hơi thở đang dùng
    quy_da_diet: list         # danh sách quỷ đã hạ
    nhat_ky: list              # log truyện, để cuối cùng in ra full story


# ============================================================
# 2. NODE — mỗi trận đánh là 1 hàm nhận state, trả về dict cập nhật
#    (không cần trả nguyên cả state, chỉ trả phần thay đổi)
# ============================================================
def final_selection(state: DemonSlayerState) -> dict:
    # Tanjiro tốt nghiệp kỳ thi tuyển chọn cuối cùng
    log = state["nhat_ky"] + ["🌸 Vượt qua Final Selection, chính thức thành Diệt Quỷ"]
    return {"hoi_tho": "Thuy", "nhat_ky": log}


def fight_rui(state: DemonSlayerState) -> dict:
    # Trận đánh với Rui - quỷ nhện ở núi Natagumo
    new_hp = state["hp"] - 30          # ăn đòn tơ nhện
    demons = state["quy_da_diet"] + ["Rui"]
    log = state["nhat_ky"] + [f"🕷️ Hạ được Rui, mất 30 HP (còn {new_hp})"]
    return {"hp": new_hp, "quy_da_diet": demons, "nhat_ky": log}


def mugen_train(state: DemonSlayerState) -> dict:
    # Trận đánh với Akaza trên chuyến tàu Vô Hạn
    new_hp = state["hp"] - 40          # Akaza mạnh hơn Rui nhiều
    log = state["nhat_ky"] + [
        f"🚂 Sống sót qua Mugen Train, đối đầu Akaza, mất 40 HP (còn {new_hp})"
    ]
    return {"hp": new_hp, "hoi_tho": "Hinokami Kagura", "nhat_ky": log}


def infinity_castle(state: DemonSlayerState) -> dict:
    # Trận cuối - Vô Diệt Thành, đối đầu Muzan
    new_hp = max(state["hp"] - 50, 1)   # gần chết nhưng vẫn cầm cự
    demons = state["quy_da_diet"] + ["Muzan"]
    log = state["nhat_ky"] + [
        f"⚔️ Đại chiến Vô Diệt Thành, hạ được Muzan, còn {new_hp} HP"
    ]
    return {"hp": new_hp, "quy_da_diet": demons, "nhat_ky": log}


# ============================================================
# 3. STATEGRAPH — Diệt Quỷ Đoàn khởi tạo bản đồ nhiệm vụ
# ============================================================
graph = StateGraph(DemonSlayerState)

# ============================================================
# 4. ADD_NODE — đăng ký từng trận đánh vào graph
# ============================================================
graph.add_node("final_selection", final_selection)
graph.add_node("fight_rui", fight_rui)
graph.add_node("mugen_train", mugen_train)
graph.add_node("infinity_castle", infinity_castle)

# ============================================================
# 5. ADD_EDGE — nối các trận theo đúng thứ tự cốt truyện
# ============================================================
graph.add_edge(START, "final_selection")
graph.add_edge("final_selection", "fight_rui")
graph.add_edge("fight_rui", "mugen_train")
graph.add_edge("mugen_train", "infinity_castle")
graph.add_edge("infinity_castle", END)

# ============================================================
# 6. COMPILE — Tanjiro "tốt nghiệp", cấu trúc hành trình đóng băng
# ============================================================
app = graph.compile()

# ============================================================
# 7. INVOKE — bấm nút chạy cả bộ truyện với 1 state khởi đầu
# ============================================================
if __name__ == "__main__":
    ket_qua = app.invoke({
        "hp": 100,
        "hoi_tho": "chua_hoc_gi",
        "quy_da_diet": [],
        "nhat_ky": [],
    })

    print("=== 📖 NHẬT KÝ PHÁ ĐẢO ===")
    for dong in ket_qua["nhat_ky"]:
        print(dong)

    print("\n=== 🏆 FINAL STATE ===")
    print(f"HP còn lại      : {ket_qua['hp']}")
    print(f"Hơi thở hiện tại: {ket_qua['hoi_tho']}")
    print(f"Quỷ đã diệt     : {ket_qua['quy_da_diet']}")
// $ python tanjiro_graph.py — output thật, đã chạy kiểm chứng 
=== 📖 NHẬT KÝ PHÁ ĐẢO ===
🌸 Vượt qua Final Selection, chính thức thành Diệt Quỷ
🕷️ Hạ được Rui, mất 30 HP (còn 70)
🚂 Sống sót qua Mugen Train, đối đầu Akaza, mất 40 HP (còn 30)
⚔️ Đại chiến Vô Diệt Thành, hạ được Muzan, còn 1 HP

=== 🏆 FINAL STATE ===
HP còn lại      : 1
Hơi thở hiện tại: Hinokami Kagura
Quỷ đã diệt     : ['Rui', 'Muzan']
TẠI SAO CHẠY ĐƯỢC Vì đây không phải giả lập — DemonSlayerState chỉ là 1 TypedDict bình thường, mỗi "trận đánh" chỉ là 1 hàm Python thuần (cộng trừ số, nối list, format string). LangGraph không quan tâm nội dung field tên gì hay ý nghĩa "HP"/"quỷ" là gì — nó chỉ chạy đúng thứ tự node theo edge, rồi merge dict trả về vào state. Đổi tên field/data thành bất kỳ câu chuyện nào bạn thích (kể cả story riêng của bạn), graph vẫn chạy y hệt logic này.
