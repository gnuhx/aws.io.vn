Lesson 3.11 — Iterative Research Agent (Loops & Cycles)

⏱ 6:23  ·  prereq: Lesson 3.10  ·  next: Lesson 3.12 (Human in the Loop)

01 Khái niệm

Iterative Research Agent là pattern LangGraph lặp lại vòng search → evaluate completeness → (loop nếu chưa đủ) cho tới khi thông tin đủ tốt hoặc chạm giới hạn an toàn max_iterations.

Ví dụ đời sống: một trợ lý nghiên cứu giỏi không trả lời sau 1 lần đọc tài liệu — họ đọc, tự hỏi "đủ chưa?", tìm thêm nếu chưa đủ, lặp lại cho tới khi tự tin hoặc hết thời gian tra cứu cho phép.

03 State với reducer

from typing import TypedDict, List, Annotated
import operator

class ResearchState(TypedDict):
    question: str
    findings: Annotated[List[str], operator.add]  # reducer: cộng dồn, không ghi đè
    iteration: int
    is_complete: bool
    final_answer: str

Annotated[List[str], operator.add] là reducer — mỗi node trả field này, LangGraph nối thêm thay vì ghi đè. Liên kết với Lesson 3.3.

04 Vòng lặp (cycle) thật sự

def should_continue(state: ResearchState) -> str:
    return "stop" if state["is_complete"] else "search_again"

builder.add_conditional_edges(
    "evaluate",
    should_continue,
    {"search_again": "search", "stop": "finalize"}  # trỏ NGƯỢC về node cũ = cycle
)

🍡 Tanjiro điều tra điểm yếu của quỷ

Trước trận đấu, Tanjiro không lao vào đánh ngay — cậu đánh hơi tìm dấu vết, rồi tự suy luận đã đủ thông tin chưa, và lặp lại nếu chưa đủ, tối đa 5 lần đánh hơi trước khi trận đấu buộc phải bắt đầu. Đây chính xác là vòng lặp search → evaluate → loop/stop của Lesson 3.11.

🗺 Ánh xạ khái niệm 1-1

State (TypedDict)
"Sổ tay điều tra" của Tanjiro — câu hỏi, dấu vết, số vòng, đã đủ tin chưa, kết luận.
search_node
Tanjiro đánh hơi (khứu giác Thủy Trụ sinh) tìm dấu vết mới mỗi vòng.
reducer operator.add
Dấu vết mới cộng dồn vào sổ tay, không xoá dấu vết cũ.
evaluate_node
Tanjiro tự suy luận xem đã đủ manh mối hạ quỷ chưa.
conditional edge (loop)
Chưa đủ → quay lại đánh hơi tiếp — cycle thật trong graph.
max_iterations = 5
Giới hạn "5 lần đánh hơi" trước trận — safety net.
finalize_node
Tanjiro chốt chiến thuật: chém đứt cổ (Kubi).
🐛 Bug node
Zenitsu đi hỗ trợ nhưng ngủ gật, mỗi vòng trả dấu vết rỗngBUG — mô phỏng node trả data rỗng mà không crash flow.

💻 Code thật (LangGraph)

"""Story Mode: Tanjiro dieu tra ky nang cua quy truoc khi giao chien."""
from typing import TypedDict, List, Annotated
from langgraph.graph import StateGraph, START, END
import operator

class SoTayDieuTraState(TypedDict):
    cau_hoi: str
    dau_vet: Annotated[List[str], operator.add]   # reducer = cộng dồn dấu vết
    so_lan_danh_hoi: int
    da_du_thong_tin: bool
    ket_luan: str

NGUON_DAU_VET = [
    "Quy co ve seo hinh chu thap tren nguc trai",
    "Quy so lua va anh sang mat troi (dac diem chung cua tat ca quy)",
    "Quy tai sinh nhanh nhung so an mon bang thanh Nichirin",
    "Quy co ky nang 'Mau Nghe Thuat' dieu khien mau lam vu khi",
    "Diem yeu that su: co (Kubi) - chem dut co la quy chet han",
]

def danh_hoi_tim_dau_vet(state): # search_node
    vong = state["so_lan_danh_hoi"] + 1
    idx = vong - 1
    dau_vet_moi = [NGUON_DAU_VET[idx]] if idx < len(NGUON_DAU_VET) else []
    return {"dau_vet": dau_vet_moi, "so_lan_danh_hoi": vong}

def zenitsu_gay_bug(state): # 🐛 bug node: ngủ gật, trả rỗng
    return {"dau_vet": []}

def suy_luan_da_du_chua(state): # evaluate_node
    co_diem_yeu_that = any("Kubi" in dv for dv in state["dau_vet"])
    du_roi = co_diem_yeu_that or state["so_lan_danh_hoi"] >= 5
    return {"da_du_thong_tin": du_roi}

def dieu_kien_lap_lai(state): # conditional edge
    return "dung_lai" if state["da_du_thong_tin"] else "danh_hoi_tiep"

builder = StateGraph(SoTayDieuTraState)
builder.add_node("danh_hoi", danh_hoi_tim_dau_vet)
builder.add_node("zenitsu_bug", zenitsu_gay_bug)
builder.add_node("suy_luan", suy_luan_da_du_chua)
builder.add_edge(START, "danh_hoi")
builder.add_edge("danh_hoi", "zenitsu_bug")
builder.add_edge("zenitsu_bug", "suy_luan")
builder.add_conditional_edges("suy_luan", dieu_kien_lap_lai,
    {"danh_hoi_tiep": "danh_hoi", "dung_lai": "ket_luan"})  # ← CYCLE thật
# ... (ket_luan node + builder.add_edge("ket_luan", END) + app = builder.compile())

🧠 Tại sao code này chạy được?

LangGraph không quan tâm field tên là dau_vet hay findings, node tên danh_hoi hay search_node. Framework chỉ cần: (1) State là TypedDict hợp lệ với reducer đúng kiểu, (2) mỗi node là hàm nhận state trả dict cập nhật đúng key, (3) add_conditional_edges map đúng string trả về sang tên node đã tồn tại. "danh_hoi_tiep" trỏ ngược về "danh_hoi" tạo cycle không phải phép màu của theme Kimetsu no Yaiba — mà vì LangGraph cho phép cạnh có điều kiện trỏ tới bất kỳ node nào, kể cả node đứng trước, miễn có logic dừng (so_lan_danh_hoi >= 5).
