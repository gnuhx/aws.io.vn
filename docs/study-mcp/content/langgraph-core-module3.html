LangGraph là gì?

Extension của LangChain cho phép xây dựng AI workflow phức tạp dưới dạng đồ thị có trạng thái (stateful graph). Khác với LCEL chains tuyến tính, LangGraph hỗ trợ vòng lặp — agent có thể reason lại sau khi quan sát kết quả.

Ví dụ đời thực: Hình dung bác sĩ nội trú xử lý bệnh nhân. Bác sĩ tiếp nhận triệu chứng → chẩn đoán → quyết định: cần thêm xét nghiệm? (quay lại) hay đủ thông tin rồi kê đơn? LCEL chỉ làm 1→2→3 thẳng. LangGraph mới làm được vòng lặp 1→2→3→2→3→4.

3 Trụ Cột (3 Pillars)

📦

STATE

TypedDict / Pydantic chứa toàn bộ dữ liệu graph cần. Mọi node đọc từ State và trả về dict để cập nhật.

≈ C#: DTO / Record class
⚙️

NODES

Function Python nhận state → xử lý → return dict (partial update). Không mutate state trực tiếp.

≈ C#: Command handler
🔀

EDGES

Xác định node nào chạy tiếp. Normal edge luôn đi A→B. Conditional edge route dựa theo logic.

≈ C#: State transitions

State & Reducers

🔄 Replace (default)

Node return dict → field bị thay thế hoàn toàn. Dùng khi muốn override giá trị.

➕ Append Reducer

Annotated[List, operator.add] — list tự động append thay vì replace. Critical cho messages.

💬 MessagesState

Built-in với add_messages reducer. Handle HumanMessage/AIMessage/ToolMessage, cùng ID → update.

🛠️ Custom Reducer

Annotated[T, my_fn] — viết logic merge phức tạp: deduplicate, merge dict, v.v.

Python State + Reducer Pattern 
from typing import TypedDict, Annotated, List
import operator
from langgraph.graph import MessagesState

# ❌ Không có reducer — replace toàn bộ
class BadState(TypedDict):
    messages: List[str]  # mỗi node xóa hết, thay bằng list mới

# ✅ Có reducer — append
class ExamGenState(TypedDict):
    messages:  Annotated[List, operator.add]  # append
    subject:   str
    exam_type: str
    topic:     str
    grade_level:      int
    generated_exam:   str
    iteration_count:  int
    needs_clarification: bool

# Built-in chat pattern
class MyChat(MessagesState):
    user_name: str  # extend thêm fields tùy ý

Build & Compile Graph

Python Full Graph Build Pattern 
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

# 1. Tạo graph
graph = StateGraph(ExamGenState)

# 2. Thêm nodes
graph.add_node("parse_request",    parse_request)
graph.add_node("generate_exam",    generate_exam)
graph.add_node("ask_clarification", ask_clarification)

# 3. Edges
graph.add_edge(START, "parse_request")
graph.add_conditional_edges(
    "parse_request",
    should_clarify,     # router fn → trả str
    {
        "ask_clarification": "ask_clarification",
        "generate_exam":     "generate_exam",
    }
)
graph.add_edge("ask_clarification", END)
graph.add_edge("generate_exam", END)

# 4. Compile (immutable sau đây)
memory = MemorySaver()
app = graph.compile(checkpointer=memory)

# 5. Invoke với thread_id
config = {"configurable": {"thread_id": "abc123"}}
result = app.invoke(initial_state, config=config)

Python ReAct Agent (1-liner vs manual) 
from langgraph.prebuilt import create_react_agent, ToolNode, tools_condition
from langchain_core.tools import tool

@tool
def search_samples(subject: str, topic: str) -> str:
    """Tìm đề mẫu từ vector store"""
    return "Đề mẫu tìm được..."

# ── Option A: 1-liner ──
agent = create_react_agent(llm, [search_samples], checkpointer=MemorySaver())

# ── Option B: manual (hiểu internals) ──
def agent_node(state: MessagesState) -> dict:
    response = llm_with_tools.invoke(state["messages"])
    return {"messages": [response]}

tool_node = ToolNode([search_samples])

graph = StateGraph(MessagesState)
graph.add_node("agent", agent_node)
graph.add_node("tools", tool_node)
graph.add_edge(START, "agent")
graph.add_conditional_edges("agent", tools_condition)
graph.add_edge("tools", "agent")  # ← LOOP!

Human in the Loop & Checkpointing

Python interrupt() + SqliteSaver 
from langgraph.types import interrupt, Command
from langgraph.checkpoint.sqlite import SqliteSaver

def review_exam(state: ExamGenState) -> dict:
    # Dừng graph, trả control về caller
    feedback = interrupt({
        "exam": state["generated_exam"],
        "msg": "Đề OK chưa? Nhập feedback:"
    })
    if feedback["approved"]:
        return {}  # giữ nguyên
    return {"messages": [feedback["feedback"]]}

# SqliteSaver — persist xuống disk
with SqliteSaver.from_conn_string("./sessions.db") as ckp:
    app = graph.compile(checkpointer=ckp)

    config = {"configurable": {"thread_id": "s001_session1"}}

    # Lần 1: chạy đến interrupt
    result = app.invoke(initial_state, config=config)

    # Lần 2: resume
    final = app.invoke(
        Command(resume={"approved": True}),
        config=config
    )

⚠️ Dễ sai — Dễ Brick

Messages bị replace: Quên dùng operator.add reducer → mỗi node xóa hết messages cũ. Fix: Annotated[List, operator.add]
thread_id không có tác dụng: Pass state mới vào invoke() mà không pass config=config → graph không biết tiếp tục session nào.
Graph chạy vô hạn: Loop không có stop condition → đặt iteration_count và check >= MAX trong conditional edge.
Tên node không nhất quán: add_node("parse",...) nhưng add_edge("parse_request","...") → KeyError khi compile. Copy-paste tên node cẩn thận.
JSON parse từ LLM: LLM thường wrap JSON trong ` ```json ... ``` ` → strip markdown trước json.loads().
