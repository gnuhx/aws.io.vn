Tại sao cần Output Parsers?

Vấn đề

LLM trả về raw string

Gọi model.invoke() → nhận AIMessage object. Muốn lấy nội dung phải gọi .content, rồi tự parse JSON, regex... rất brittle.

# Không parser — nhận AIMessage
res = llm.invoke("Rate this product")
print(type(res))  # <AIMessage>
# Phải tự split, regex, strip...
Giải pháp

Output Parser = auto-convert

Parser nằm cuối chain, tự động convert output của LLM thành kiểu dữ liệu bạn muốn: string, dict, hay Pydantic model.

chain = prompt | model | StrOutputParser()

JsonOutputParser

Parse JSON string → Python dict

⚠️ Prompt phải nói rõ "Return ONLY valid JSON, no markdown" — LLM hay thêm ```json ``` block!
from langchain_core.output_parsers import JsonOutputParser

parser = JsonOutputParser()

prompt = ChatPromptTemplate.from_template("""
Analyze review, return JSON with: rating(int), pros(list), cons(list)
Review: {review}
Return ONLY valid JSON, no markdown.""")

chain = prompt | ChatOpenAI(model="gpt-4o-mini") | parser

result = chain.invoke({"review": "iPhone 15 is great but expensive"})
print(result["rating"])  # 4
print(result["pros"])    # ['great camera', ...]
PydanticOutputParser — Type-Safe

Parse + Validate → Pydantic Model instance

from langchain_core.output_parsers import PydanticOutputParser
from pydantic import BaseModel, Field
from typing import List

class ProductReview(BaseModel):
    rating: int = Field(description="Rating 1-5")
    pros: List[str] = Field(description="Positive aspects")
    cons: List[str] = Field(description="Negative aspects")

parser = PydanticOutputParser(pydantic_object=ProductReview)

# Parser tự generate format instructions!
prompt = ChatPromptTemplate.from_template(
    "{format_instructions}\nReview: {review}"
).partial(format_instructions=parser.get_format_instructions())

chain = prompt | ChatOpenAI(model="gpt-4o-mini") | parser

result = chain.invoke({"review": "Great phone!"})
print(type(result))    # <class 'ProductReview'>
print(result.rating)   # 4  ← int thật, không phải "4"
print(result.pros)     # list thật, IDE autocomplete được
with_structured_output() — Native JSON Mode

Model tự handle format — tin cậy nhất cho production

# Không cần output parser tách biệt!
model = ChatOpenAI(model="gpt-4o-mini")
structured = model.with_structured_output(ProductReview)

result = structured.invoke("Review: iPhone 15 is great but expensive")
print(result.rating)  # 4 — guaranteed

Streaming — Real-time Output

Ví dụ đời sống: Không streaming = nhận email khi người kia gõ xong hết. Streaming = thấy từng chữ xuất hiện ngay khi họ gõ → cảm giác nhanh hơn nhiều dù tổng thời gian giống nhau.

# Sync streaming
for chunk in chain.stream({"topic": "Python"}):
    print(chunk, end="", flush=True)  # flush=True bắt buộc!
print()  # newline cuối

# Async streaming (FastAPI / production)
async def stream_resp(topic):
    async for chunk in chain.astream({"topic": topic}):
        yield chunk  # StreamingResponse trong FastAPI

# JSON streaming — nhận partial dict ngày càng đầy
for partial in (prompt | model | JsonOutputParser()).stream(input):
    print(partial)
    # {} → {"rating": 4} → {"rating": 4, "pros": []} → ...

Batch & Execution Methods

MethodUse CaseReturn
.invoke(input)1 input, chờ full outputobject
.stream(input)1 input, nhận từng tokengenerator
.batch(inputs)N inputs, chạy song songlist
.ainvoke(input)Async invokecoroutine
.astream(input)Async streamasync gen
.abatch(inputs)Async batchcoroutine→list
 
# Batch với max concurrency
results = chain.batch(
    [{"q": q} for q in questions],
    config={"max_concurrency": 5}
)

# Batch không crash khi 1 item lỗi
results = chain.batch(inputs, return_exceptions=True)
for r in results:
    if isinstance(r, Exception): print(f"Failed: {r}")
    else: print(r)

🎯 Streaming Patterns
# Sync stream
for chunk in chain.stream(input):
    print(chunk, end="", flush=True)

async for chunk in chain.astream(input):

📦 Batch Patterns
# Basic batch
results = chain.batch([{"q": q} for q in questions])

# With concurrency limit (avoid rate limit)
results = chain.batch(inputs, config={"max_concurrency": 5})

# Don't crash on 1 failure
results = chain.batch(inputs, return_exceptions=True)
for r in results:
    if isinstance(r, Exception): print(f"❌ {r}")
