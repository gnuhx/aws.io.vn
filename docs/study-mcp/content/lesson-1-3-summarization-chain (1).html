01 Khái niệm + Ví dụ đời sống

Summarization Chain là pipeline 3 bước nối nhau bằng LCEL pipe operator |:

chain = prompt | model | parser

Ví dụ đời sống: giống một trợ lý văn phòng — bạn đưa bài báo dài (input), dặn "tóm tắt 3 câu" (prompt template), trợ lý đọc và viết tóm tắt (model), bạn nhận lại bản tóm tắt sạch không có lời dẫn thừa (output parser).

03 Các lệnh quan trọng + Nâng cao

Prompt Template

from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "Bạn là trợ lý tóm tắt văn bản..."),
    ("human", "Tóm tắt văn bản sau:\n\n{text}")
])
  • from_messages([...]): nhận list tuple (role, content)
  • "system": định nghĩa hành vi tổng quát của model
  • "human": input thật của người dùng, chứa placeholder {text}

Chat Model

from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4o-mini", temperature=0)
FlagÝ nghĩa
model="gpt-4o-mini"Model nhẹ, rẻ — đủ cho task tóm tắt
temperature=0Deterministic, ổn định — khuyên dùng cho summarization
max_tokens=... (nâng cao)Giới hạn độ dài output
model_kwargs={"top_p":...} (nâng cao)Fine-tune sampling khi temperature > 0

Output Parser

from langchain_core.output_parsers import StrOutputParser

parser = StrOutputParser()

Chuyển AIMessage (object) thành string thuần — parser đơn giản nhất, không cần config.

Compose & chạy chain

chain = prompt | model | parser

result = chain.invoke({"text": long_article_text})
print(result)

Runnable methods nâng cao

MethodDùng khi
.invoke(input)Chạy 1 lần, trả kết quả hoàn chỉnh
.stream(input)Trả từng token — UI hiển thị real-time
.batch([i1, i2])Chạy song song nhiều input
.ainvoke(input)Phiên bản async — dùng trong web server

🧪 Lab steps tóm tắt

  1. Tạo venv + cài deps
  2. Tạo .env với API key
  3. Viết summarize.py: prompt, model, parser, chain

⚠️ Dễ sai

  • Quên load_dotenv() → AuthenticationError
  • Quên | parser → trả về AIMessage thay vì string
  • Văn bản quá dài → RateLimitError / vượt token limit
  • System prompt không rõ → output dính lời dẫn thừa
