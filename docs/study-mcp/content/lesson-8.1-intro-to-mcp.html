01 Khái niệm + ví dụ đời sống

MCP là gì?

Model Context Protocol (MCP) là giao thức mở do Anthropic tạo ra, chuẩn hoá cách AI agent kết nối với dữ liệu và công cụ bên ngoài (database, file system, API, search engine...).

Ẩn dụ: Trước USB-C, mỗi hãng điện thoại có chân sạc riêng (Nokia, micro-USB, Lightning) → cần N loại dây cho N thiết bị. Sau USB-C: 1 cổng chuẩn cắm được mọi thiết bị.

AI Agent gặp đúng vấn đề đó trước MCP: mỗi framework (LangChain, CrewAI, AutoGen...) phải viết integration riêng cho từng tool bên ngoài (Slack, Drive, DB...).

🍡 Tanjiro và Chuẩn "Hơi Thở" của các Trụ Cột

Tanjiro Kamado mang Nichirin Blade đi khắp nơi xin các Hashira (Trụ Cột) chỉ dạy. Mỗi Hashira — Thuỷ Trụ Giyu, Viêm Trụ Rengoku, Nham Trụ Gyomei — có chiêu thức riêng, nhưng tất cả đều giao tiếp qua chuẩn Hơi Thở (Kokyuu) chung. Tanjiro không cần học lại cách tương tác từ đầu mỗi lần gặp Hashira mới — vì ai cũng tuân theo cùng 1 chuẩn.

05a Ánh xạ khái niệm ↔ chi tiết truyện

MCP Server Mỗi vị Hashira = 1 server độc lập, mỗi người tự có "tool" (chiêu thức) riêng nhưng đều expose qua cùng 1 chuẩn giao tiếp.
MCP Client Tanjiro = client — dùng đúng 1 cách "hỏi chiêu" (list_tools, call_tool) để tương tác với bất kỳ Hashira nào, không cần học lại cách giao tiếp mỗi lần đổi sư phụ.
initialize() / Handshake Nghi thức bái sư trước khi được truyền chiêu — bỏ qua bước này thì Hashira không dạy (server từ chối phục vụ request chưa handshake).
@mcp.tool() Chiêu thức được đăng ký chính thức trong "sổ Hơi Thở" của môn phái — chỉ chiêu đã đăng ký mới gọi được, tên chiêu + mô tả (docstring) được ghi rõ để đệ tử tra cứu.
🐛 Bug hài hước Đệ tử Zenitsu hoảng loạn giữa buổi tập, gọi nhầm tên chiêu (call_tool sai tên đã đăng ký) → hệ thống trả lỗi "Tool không tồn tại", cả nhóm phải đợi Zenitsu tỉnh táo lại mới gọi đúng.

05b Code thật — đã chạy kiểm chứng

usbc_server.py (Hashira mở "cổng dạy chiêu")

from mcp.server.fastmcp import FastMCP

# "Cong USB-C" - server duy nhat, expose 2 tools chuan hoa
mcp = FastMCP("cong_usbc_demo")

@mcp.tool()
def sac_pin_thiet_bi(ten_thiet_bi: str, phan_tram_pin: int) -> str:
    """Gia lap 'sac pin' cho 1 thiet bi bat ky cam vao cong USB-C (tool)."""
    pin_moi = min(100, phan_tram_pin + 35)
    return f"[{ten_thiet_bi}] da sac tu {phan_tram_pin}% len {pin_moi}% qua cong chuan MCP."

@mcp.tool()
def doc_du_lieu_thiet_bi(ten_thiet_bi: str) -> str:
    """Gia lap doc du lieu tu 1 thiet bi (resource-like tool) qua cung 1 cong."""
    return f"[{ten_thiet_bi}] tra ve du lieu: {{'trang_thai': 'ok', 'nguon': 'MCP server'}}"

if __name__ == "__main__":
    mcp.run(transport="stdio")

usbc_client.py (Tanjiro hỏi chiêu 2 Hashira)

import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def chay_thu_nghiem():
    server_params = StdioServerParameters(
        command="python3",
        args=["/home/claude/mcp_demo/usbc_server.py"],
    )
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()  # "bai su" truoc khi duoc day chieu

            danh_sach_tools = await session.list_tools()
            print("=== Danh sach tools server cong khai ===")
            for tool in danh_sach_tools.tools:
                print(f"- {tool.name}: {tool.description}")

            ket_qua_a = await session.call_tool(
                "sac_pin_thiet_bi",
                arguments={"ten_thiet_bi": "Laptop-FrameworkA", "phan_tram_pin": 20},
            )
            print(ket_qua_a.content[0].text)

            ket_qua_b = await session.call_tool(
                "doc_du_lieu_thiet_bi",
                arguments={"ten_thiet_bi": "Dien-thoai-FrameworkB"},
            )
            print(ket_qua_b.content[0].text)

asyncio.run(chay_thu_nghiem())
Output thật, đã chạy kiểm chứng
Processing request of type ListToolsRequest === Danh sach tools server cong khai === - sac_pin_thiet_bi: Gia lap 'sac pin' cho 1 thiet bi bat ky cam vao cong USB-C (tool). - doc_du_lieu_thiet_bi: Gia lap doc du lieu tu 1 thiet bi (resource-like tool) qua cung 1 cong. === Thiet bi A goi tool sac_pin_thiet_bi === Processing request of type CallToolRequest [Laptop-FrameworkA] da sac tu 20% len 55% qua cong chuan MCP. === Thiet bi B goi tool doc_du_lieu_thiet_bi === Processing request of type CallToolRequest [Dien-thoai-FrameworkB] tra ve du lieu: {'trang_thai': 'ok', 'nguon': 'MCP server'}
Tại sao code này chạy được: FastMCP và ClientSession không quan tâm tên hàm là sac_pin_thiet_bi hay Hashira nào đứng đằng sau ẩn dụ — framework chỉ quan tâm đúng thứ tự giao thức: (1) client spawn/kết nối server qua transport đã khai, (2) initialize() để handshake JSON-RPC, (3) list_tools() lấy schema (tên hàm + docstring + type hint tự động serialize), (4) call_tool(ten, arguments) đúng tên đã đăng ký bằng @mcp.tool(). Đổi hết tên biến sang tiếng Việt không dấu, code vẫn chạy y hệt — vì đây không phải phép màu "Hơi Thở", mà do nắm đúng nguyên lý decorator + JSON-RPC mà SDK cung cấp.
