WHY LANGGRAPH?

LangGraph vs LCEL Chain

LCEL phù hợp cho pipeline tuyến tính. LangGraph được thiết kế khi bạn cần cycles, branching, và human-in-the-loop.

PILLAR 1

STATE — Bộ nhớ của Graph

🎯 Ví dụ đời sống: State như cái bảng trắng trong phòng họp. Mỗi người (node) vào phòng, đọc bảng, viết thêm thông tin, rồi người tiếp theo vào làm tiếp. Bảng luôn có trạng thái mới nhất của cuộc họp.

State là TypedDict chứa toàn bộ dữ liệu đang chạy qua graph. Node đọc từ và ghi vào State.

from typing import TypedDict, List, Annotated
import operator

# State cơ bản — fields thay thế khi update
class ExamGenState(TypedDict):
    user_request: str     # Raw input từ user
    subject: str          # "math", "english"
    grade: int            # 6, 9, 12...
    exam_json: str        # JSON đề thi output

# State nâng cao — Reducer: list tự APPEND thay vì replace
class AgentState(TypedDict):
    messages: Annotated[List[str], operator.add]  # Accumulate!
    current_step: str
    error_count: int

Quy tắc: Node return dict chứa chỉ các fields muốn update — không cần return toàn bộ State.

PILLAR 2

NODES — Các bước xử lý

🏭 Ví dụ đời sống: Node như các trạm trong dây chuyền sản xuất. Xe hơi (State) đi qua trạm sơn, trạm lắp nội thất, mỗi trạm thêm/thay đổi một phần của chiếc xe. Trạm không tạo ra chiếc xe mới — chỉ modify nó.
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

llm = ChatOpenAI(model="gpt-4o-mini")

# ✅ Node chuẩn: nhận state, return dict với fields muốn update
def parse_request_node(state: ExamGenState) -> dict:
    raw = state["user_request"]
    # gọi LLM để extract thông tin
    response = llm.invoke([HumanMessage(content=raw)])
    return {"subject": "english", "grade": 6}

# ✅ Node gọi LLM
def generate_exam_node(state: ExamGenState) -> dict:
    prompt = f"Tạo đề {state['subject']} lớp {state['grade']}"
    response = llm.invoke([HumanMessage(content=prompt)])
    return {"exam_json": response.content}

# ❌ SAI: Node mutate state trực tiếp — KHÔNG LÀM VẬY
def bad_node(state: ExamGenState) -> dict:
    state["subject"] = "english"  # ❌ mutate!
    return state                    # ❌ return toàn bộ state
PILLAR 3

EDGES — Luồng chuyển tiếp

🛣 Ví dụ đời sống: Edge như biển chỉ đường. Normal edge = đường cao tốc một chiều bắt buộc. Conditional edge = ngã tư có đèn xanh/đỏ, rẽ trái/phải tùy tình huống.

3 loại Edge:

from langgraph.graph import StateGraph, START, END

builder = StateGraph(ExamGenState)

# 1. NORMAL EDGE — luôn đi từ A → B
builder.add_edge(START, "parse_request")
builder.add_edge("parse_request", "validate")
builder.add_edge("generate_exam", END)

# 2. CONDITIONAL EDGE — function quyết định đường đi
def route_after_validate(state: ExamGenState) -> str:
    # Return TÊN NODE tiếp theo dưới dạng string
    if state["subject"] == "unknown":
        return "ask_clarification"
    return "generate_exam"

builder.add_conditional_edges(
    "validate",           # Từ node nào
    route_after_validate,   # Function routing
    {                       # Mapping (optional)
        "ask_clarification": "ask_clarification",
        "generate_exam": "generate_exam"
    }
)
COMPILE & RUN

Compile → Immutable → Invoke

Sau compile(), graph trở thành immutable — không thể add node/edge nữa. Đây là thiết kế có chủ ý để graph safe khi chạy concurrent.

# Compile một lần
app = builder.compile()

# Invoke: chạy đến END, trả về final state
result = app.invoke({
    "user_request": "cho đề tiếng anh 15 phút lớp 6",
    "subject": "", "grade": 0, "exam_json": ""
})

# Stream: nhận state update sau từng node (real-time)
for step in app.stream(initial_state):
    node_name = list(step.keys())[0]
    print(f"✓ Completed: {node_name}")

# Visualize
print(app.get_graph().draw_mermaid())
# app.get_graph().draw_mermaid_png()  # cần thư viện bổ sung

⚠️ Những thứ dễ sai:
  • Quên khởi tạo đủ fields trong initial_state → KeyError
  • Node mutate state trực tiếp (state["x"] = ...) thay vì return dict
  • Thiếu edge về END → graph treo mãi hoặc không compile
  • Compile xong rồi mới add_node → không có tác dụng
  • LLM trả về markdown (```json...```) → json.loads fail → cần strip
