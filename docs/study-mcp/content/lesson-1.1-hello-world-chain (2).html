🎯 Khái niệm cốt lõi

LangChain là framework giúp nối LLM với các thành phần khác (prompt, parser, tool, memory) theo kiểu lắp ghép Lego. LCEL (LangChain Expression Language) dùng operator | để compose các Runnable component thành một chain.

☕ Ví dụ đời sống: Hãy nghĩ về dây chuyền pha cà phê tự động — PromptTemplate là công thức pha (có chỗ trống điền nguyên liệu), ChatOpenAI là máy pha, StrOutputParser là máy đổ ly thành phẩm. Pipe | chính là băng chuyền nối các máy lại với nhau.

So sánh với C# / .NET backend

LangChain (Python)C# tương đương
PromptTemplateString template / Razor template
ChatOpenAIHttpClient gọi API (model wrapper)
StrOutputParserResponse DTO mapper
prompt | model | parserMiddleware pipeline (app.Use(...))
chain.invoke(input)Gọi pipeline đồng bộ
chain.batch([...])Task.WhenAll(...)

hello_world.py — Chain đầu tiên

from dotenv import load_dotenv
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

load_dotenv()

# 1. Prompt Template — công thức có chỗ trống
prompt = PromptTemplate.from_template("Hãy nói lời chào bằng tiếng {language}: {input}")

# 2. Model — máy pha
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)

# 3. Output Parser — chuyển kết quả về string
parser = StrOutputParser()

# 4. LCEL Chain — ghép bằng pipe operator
chain = prompt | model | parser

# 5. Invoke
result = chain.invoke({"language": "Việt", "input": "Hello World"})
print(result)
PhầnGiải thích
load_dotenv()Đọc file .env, nạp key vào os.environ
PromptTemplate.from_template()Tạo template với placeholder {language}, {input}
ChatOpenAI(model=, temperature=)temperature: 0 = deterministic, gần 1 = sáng tạo/ngẫu nhiên hơn
StrOutputParser()Lấy .content string từ object AIMessage
prompt | model | parserCompose 3 Runnable thành 1 chain duy nhất
chain.invoke({...})Chạy chain đồng bộ, trả kết quả cuối

🏢 Ứng dụng thực tế

  • Chatbot/Customer support: chain prompt | model | parser là core của mọi chatbot.
  • Content generation pipelines: sequential chaining để tạo draft rồi polish bằng chain khác.
  • Internal tools tại công ty (.NET/Java backend): microservice Python wrap LangChain chain, expose qua FastAPI, gọi từ hệ thống chính qua HTTP.
  • Prototype nhanh: cú pháp ngắn gọn giúp validate ý tưởng AI product trong vài giờ.
