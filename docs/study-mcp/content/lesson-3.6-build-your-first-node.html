🎯 Khái niệm

Một Node trong LangGraph chỉ là một hàm Python nhận state làm input và trả về một dict chứa những field bị thay đổi.

def my_node(state: MyState) -> dict:
    # đọc, xử lý, rồi trả field bị thay đổi
    return {"field": new_value}

🍔 Ví dụ đời sống

Dây chuyền làm burger: State = cái khay trôi trên băng chuyền. Node = một trạm (VD: "trạm nướng thịt") — chỉ làm đúng 1 việc, cập nhật đúng phần của mình lên khay, không đổ hết đồ đi làm lại. Nếu bếp hết gas, trạm phải có phương án dự phòng chứ không được đứng hình làm nghẽn cả dây chuyền.

📄 "File cấu hình" tương đương

State schema (TypedDict) đóng vai trò như file cấu hình định nghĩa hình dạng dữ liệu:

from typing import TypedDict, Optional

class ResearchState(TypedDict):
    question: str
    findings: Optional[str]
    error: Optional[str]

Kèm .env nếu node gọi API thật — không bao giờ hard-code key trong node function.

🏢 Ứng dụng thực tế

⚠️ Top lỗi dễ mắc

• Return None thay vì dict
• Trả nguyên state cũ thay vì chỉ field thay đổi
• Không try/except quanh phần gọi API
• Mutate trực tiếp state thay vì return dict mới
• Hard-code API key trong node function

Thầy Urokodaki từng bắt Tanjiro đeo mặt nạ hồ ly suốt 2 năm trước khi cho lên núi thi đấu. Tại sao? Vì nếu tay nghề (type) chưa đúng chuẩn, xuống núi sẽ toi mạng ngay chiêu đầu.

State typing = "chuẩn tay nghề" Viết def research_node(state: ResearchState) -> dict giống việc thầy Urokodaki bắt con kiểm tra đúng tư thế trước — nếu gõ sai tên field (giống vung kiếm sai góc), cả graph sẽ "gãy kiếm" giữa trận chứ không đợi đến lúc lên núi thật (production) mới lộ ra.

Tanjiro Kamado

Khi chiến đấu với quỷ máu ở đường hầm, Tanjiro từng bị đứt mũi ngửi (giác quan chính) — nhưng cậu không gục ngã, cậu chuyển sang dùng tai và trực giác để tiếp tục chiến đấu.

try/except = "Tổng Tập Trung Hơi Thở" Đó chính là try/except: khi "giác quan chính" (search API) bị hỏng đột ngột, node không được "ngã gục" (crash cả graph) — nó phải trả về {"error": "..."} giống Tanjiro chuyển sang chế độ "Tổng Tập Trung Hơi Thở Thường Trực" để không đứt hơi giữa trận.
