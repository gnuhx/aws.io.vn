🧭 Ví dụ đời sống

LCEL = đi thẳng một con đường một chiều. LangGraph = lái xe trong thành phố có vòng xoay, đèn đỏ, được quay đầu, có trạm dừng chờ người.

02 LCEL vs LangGraph

LCEL (chain)LangGraph (graph)
Ẩn dụĐường thẳng 1 chiềuThành phố có vòng xoay, đèn đỏ
Rẽ nhánhKhôngCó (conditional edges)
Vòng lặpKhôngCó (cycle + stop condition)
Con người can thiệpKhông hỗ trợ nativeinterrupt() + resume
Nhớ trạng tháiKhôngCheckpointer (Memory/Sqlite/Postgres)

03 5 Pattern quan trọng nhất

① Pipeline

A → B → C tuần tự, không rẽ nhánh.

② Routing

add_conditional_edges chọn node kế tiếp theo state.

③ Loop

Cycle quay lại chính nó, luôn cần stop condition.

④ Human-in-the-loop

interrupt() dừng chờ người, resume bằng Command.

⑤ Checkpoint

Lưu state mỗi super-step, hỗ trợ time travel.

START
→
pipeline node
→
routing (if/else)
→
loop (retry?)
↺
interrupt (human?)
→
END

04 Code minh hoạ 3 pattern kết hợp

from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

class TaskState(TypedDict):
    task_type: str
    attempts: int
    solved: bool

# Routing: chọn path theo state
def route_fn(state):
    return "easy_path" if state["task_type"] == "easy" else "hard_path"

# Loop: dừng khi solved hoặc quá 5 lần thử
def check_fn(state):
    return "done" if state["solved"] or state["attempts"] >= 5 else "retry"

graph.add_conditional_edges("classify", route_fn, {...})
graph.add_conditional_edges("solve", check_fn, {"retry": "solve", "done": END})

checkpointer = MemorySaver()  # pattern ⑤: checkpoint
app = graph.compile(checkpointer=checkpointer)

05 Production checklist

  • ✅ Xác định rõ cần graph hay chỉ cần chain
  • ✅ Mọi loop đều có stop condition
  • ✅ Checkpointer đúng môi trường: MemorySaver (dev) / SqliteSaver, PostgresSaver (prod)
  • ✅ thread_id riêng cho từng phiên/nhiệm vụ
  • ✅ Quyết định rủi ro cao có human-in-the-loop
  • ✅ Log state qua từng bước để debug

🍡 Story Mode — Tanjiro học LangGraph

📖 Nhiệm vụ diệt quỷ ở làng ven núi Kumo

Tanjiro Kamado nhận nhiệm vụ diệt quỷ. Cuốn Sổ Tay Nhiệm Vụ mà quạ Kasugai Karasu giao cho cậu chính là State — nó ghi lại: loại quỷ, kỹ thuật đang dùng, số lần tấn công, sức lực còn lại.

Đầu tiên, Tanjiro Điều tra (node dieu_tra) — đánh hơi xác định loại quỷ. Đây là bước đầu của Pipeline: cố định, tuần tự, không thể bỏ qua.

Sau đó cậu Chọn kỹ thuật thở (node chon_ky_thuat) — đây chính là Routing: nếu là quỷ Thượng Trụ, cậu dùng "Hơi Thở Thuỷ Bậc 11"; nếu chỉ là quỷ thường, dùng "Bậc 1". Quyết định rẽ nhánh này y hệt add_conditional_edges chọn node kế tiếp dựa trên state.

Rồi Tanjiro Tấn công lặp lại (node tan_cong) — đây là Loop: cậu đánh liên tục cho đến khi hạ gục quỷ hoặc kiệt sức (tối đa 5 lần — giống hệt max iterations để tránh vòng lặp vô tận).

Mỗi bước đi qua, con quạ Kasugai Karasu lại ghi nhớ lại — đó chính là Checkpoint (MemorySaver). Nhờ vậy nếu Tanjiro cần "xem lại" toàn bộ hành trình nhiệm vụ, cậu chỉ cần hỏi quạ — giống hệt gọi get_state_history() để time travel.

🐛 Bug hài hước: Nếu Inosuke (nóng vội, không chịu nghe kế hoạch) nhảy thẳng vào node Tấn công mà bỏ qua bước Điều tra, state sẽ thiếu field loai_quy → graph lập tức báo lỗi KeyError, y hệt khi dev quên khai báo đủ field bắt buộc trong TypedDict.

🍡 Code thật (đã chạy kiểm chứng)

from typing import TypedDict, Literal
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

class NhiemVuState(TypedDict):
    ten_nhiem_vu: str
    loai_quy: str
    ky_thuat: str
    so_lan_tan_cong: int
    suc_luc: int
    da_ha_guc: bool
    lich_su: list[str]

def dieu_tra_node(state):
    log = f"[Điều tra] Tanjiro đánh hơi thấy mùi quỷ tại '{state['ten_nhiem_vu']}', xác định loại: {state['loai_quy']}"
    return {"lich_su": state["lich_su"] + [log]}

def chon_ky_thuat_node(state):
    ky_thuat = ("Hơi Thở Thuỷ - Bậc 11: Chảy Trôi Vô Tận"
                if state["loai_quy"] == "quy_thuong_tru"
                else "Hơi Thở Thuỷ - Bậc 1: Mặt Nước")
    return {"ky_thuat": ky_thuat,
            "lich_su": state["lich_su"] + [f"[Routing] Đã chọn: {ky_thuat}"]}

def route_theo_loai_quy(state) -> Literal["tan_cong_manh", "tan_cong_thuong"]:
    return "tan_cong_manh" if state["loai_quy"] == "quy_thuong_tru" else "tan_cong_thuong"

def tan_cong_node(state):
    lan = state["so_lan_tan_cong"] + 1
    suc_luc_moi = state["suc_luc"] - 15
    can_bao_nhieu_don = 3 if state["loai_quy"] == "quy_thuong_tru" else 2
    ha_guc = lan >= can_bao_nhieu_don
    log = f"[Tấn công lần {lan}] Dùng '{state['ky_thuat']}' — sức lực còn {suc_luc_moi}"
    if ha_guc: log += " → QUỶ BỊ HẠ GỤC!"
    return {"so_lan_tan_cong": lan, "suc_luc": suc_luc_moi,
            "da_ha_guc": ha_guc, "lich_su": state["lich_su"] + [log]}

def kiem_tra_ket_qua(state) -> Literal["tan_cong_tiep", "bao_cao"]:
    if state["da_ha_guc"] or state["suc_luc"] <= 0 or state["so_lan_tan_cong"] >= 5:
        return "bao_cao"
    return "tan_cong_tiep"

graph = StateGraph(NhiemVuState)
graph.add_node("dieu_tra", dieu_tra_node)
graph.add_node("chon_ky_thuat", chon_ky_thuat_node)
graph.add_node("tan_cong_manh", tan_cong_node)
graph.add_node("tan_cong_thuong", tan_cong_node)
graph.add_conditional_edges("chon_ky_thuat", route_theo_loai_quy,
    {"tan_cong_manh": "tan_cong_manh", "tan_cong_thuong": "tan_cong_thuong"})
graph.add_conditional_edges("tan_cong_manh", kiem_tra_ket_qua,
    {"tan_cong_tiep": "tan_cong_manh", "bao_cao": "bao_cao"})

checkpointer = MemorySaver()  # Ký ức quạ Kasugai Karasu
app = graph.compile(checkpointer=checkpointer)

config = {"configurable": {"thread_id": "nhiem_vu_001"}}
ket_qua = app.invoke({"ten_nhiem_vu": "Làng ven núi Kumo", "loai_quy": "quy_thuong_tru",
    "ky_thuat": "", "so_lan_tan_cong": 0, "suc_luc": 100,
    "da_ha_guc": False, "lich_su": []}, config)

LangGraph không quan tâm tên field trong TypedDict hay tên node là gì — nó chỉ quan tâm 3 điều: state đúng shape khai báo, hàm node trả về dict hợp lệ, và hàm điều kiện của add_conditional_edges trả đúng 1 key có trong mapping. Đổi tên biến sang tiếng Việt theo theme Kimetsu no Yaiba không hề ảnh hưởng cách graph vận hành — đây không phải phép màu của theme, mà vì bản chất LangGraph chạy thuần logic state → node → edge, độc lập hoàn toàn với ngữ nghĩa đặt tên.
