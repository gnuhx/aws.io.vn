1. Khái niệm

Cycle trong LangGraph

Cycle là khi một node được phép quay lại một node đã chạy trước đó, thay vì luôn đi tới trước như một DAG (Directed Acyclic Graph). Đây là lý do LangGraph tồn tại tách biệt với LangChain: chain = luôn đi thẳng, graph = cho phép có chu trình.

generate_code
→
run_tests
→ (fail) →
quay lại generate_code
→ ... → (pass) →
END

Self-Correcting Code Writer = ứng dụng kinh điển của cycle: LLM viết code → chạy thử → lỗi được đưa ngược lại cho LLM → LLM sửa dựa trên lỗi cụ thể → lặp tới khi pass hoặc hết lượt.

Ví dụ đời sống

Học sinh giải bài tập → nộp → giáo viên chấm sai và ghi chú lỗi cụ thể → học sinh đọc chú thích, sửa đúng chỗ sai đó (không làm lại từ đầu) → nộp lại → lặp tối đa 3 lần, nếu vẫn sai thì giáo viên dừng lại và hướng dẫn trực tiếp.

Điểm mấu chốt: đây không phải lặp mù quáng, mà lặp có feedback cụ thể + điều kiện dừng rõ ràng.

3. Thành phần & API quan trọng

State fields

class CodeWriterState(TypedDict):
    code: str                  # code hiện tại
    error: Optional[str]       # lỗi lần gần nhất (None nếu pass)
    attempts: int              # đếm số lần đã thử
    max_attempts: int          # giới hạn — tránh infinite loop
    success: bool

Conditional edge tạo ra cycle

graph.add_conditional_edges(
    "run_tests",              # node nguồn
    check_result,              # hàm điều kiện -> trả string
    {
        "done": END,
        "give_up": END,
        "retry": "generate_code",   # <-- dòng này tạo CYCLE
    },
)
source node

Node mà sau khi chạy xong sẽ gọi hàm điều kiện.

condition_fn

Nhận state, trả về 1 string literal — LangGraph tra string này trong mapping.

mapping (dict)

Map string → tên node tiếp theo hoặc END. Key trỏ về node cũ = tạo cycle.

recursion_limit nâng cao

app.invoke(state, config={"recursion_limit": 20}) — giới hạn cứng ở tầng framework, độc lập với max_attempts tự track trong state.

2 cách chạy/test code trong node

# Cách 1: exec() - nhanh, KHÔNG an toàn với code không tin cậy
exec(code_string, namespace)

# Cách 2: subprocess - an toàn hơn, chạy process riêng, có timeout
import subprocess
result = subprocess.run(
    ["python3", "-c", code_string],
    capture_output=True, text=True, timeout=5
)

5. Ứng dụng thực tế

  • Cursor / Windsurf / Replit Agent: agent viết code, tự chạy test, tự sửa khi lỗi — cycle pattern ở quy mô lớn hơn.
  • CI/CD self-healing: agent nhận log lỗi build fail → tự generate patch → push lại → CI chạy lại (retry loop có giới hạn).
  • Code review bot nội bộ: generate code từ spec → chạy unit test có sẵn → fail thì gửi lại error cho LLM, lặp tối đa N lần trước khi escalate cho human.
  • Exam Generator (project của bạn): pattern nền cho "v2: Clarify + Refine loop" — user feedback → quay lại generate_exam với constraint mới, tối đa N lần refine.

Lab steps tóm tắt

  1. pip install langgraph langchain-core
  2. Định nghĩa CodeWriterState (TypedDict)
  3. Viết node generate_code (check state["error"] để quyết định fix hay tạo mới)
  4. Viết node run_tests (exec + assert, trả về error/success)
  5. Viết check_result trả về "done"/"retry"/"give_up"
  6. Nối graph: START → generate_code → run_tests, conditional edges với "retry" → generate_code
  7. Compile & chạy với recursion_limit=20
  8. Verify: attempts ≤ max_attempts, thử đổi max_attempts=1 để test nhánh give_up

⚠️ Bẫy thường gặp

  • Quên recursion_limit → infinite loop thật nếu logic có bug
  • String literal không khớp key trong mapping (VD: "Retry" vs "retry") → KeyError lúc runtime
  • Quên reset error = None khi test pass
  • exec() với code không tin cậy trong production
  • Tăng attempts sai node → lệch số đếm

🍡 Story Mode — Tanjiro luyện "Nhất Hướng Hội Chuyển"

Bối cảnh

Tanjiro đứng dưới thác nước, được Urokodaki giao nhiệm vụ: chém đứt một tảng đá lớn bằng một chiêu kiếm đúng chuẩn. Đây là vòng lặp luyện tập = cycle của LangGraph mà cậu phải trải qua.

Diễn biến

Urokodaki: "Chém tảng đá đó vỡ ra cho ta xem." START → luyen_chieu
Tanjiro vung kiếm theo bản năng, quên mất nhịp xoay cổ tay. generate_code (lần đầu, có "bug")
Zenitsu (đang ngủ gật) vẫn lầm bầm chấm điểm: "Đá... chưa vỡ đâu Tanjiro..." run_tests → error
🐛 Bug hài hước: Inosuke nhảy xổ vào giữa lúc Tanjiro đang tập trung, hét "Đấu với ta!" — làm Tanjiro giật mình chém trượt thêm 1 nhịp. Urokodaki phải quát Inosuke ra khỏi vòng lặp trước khi cho Tanjiro thử lại — giống hệt việc một exception ngẫu nhiên (side-effect ngoài ý muốn) làm hỏng 1 lần chạy test, cần bắt riêng exception đó thay vì để nó phá vòng lặp chính.
Tanjiro ngửi thấy "mùi" của thất bại (chính là error message) và tự điều chỉnh: xoay cổ tay đúng nhịp. error → fix trong generate_code (retry)
Zenitsu giật mình tỉnh: "Ơ... vỡ rồi kìa!" run_tests → success=True
Urokodaki: cấp chứng nhận, kết thúc bài kiểm tra. check_result → "dat_chung_nhan" → END
Nếu sau 3 lần vẫn không vỡ được đá, Urokodaki sẽ đuổi Tanjiro về núi luyện lại từ đầu. max_attempts → "duoi_ve_nui" → END

Code (thật, đã chạy kiểm chứng)

from typing import TypedDict, Optional
from langgraph.graph import StateGraph, START, END


# State = cuốn sổ tay Urokodaki bắt Tanjiro ghi lại sau mỗi lần luyện
class TanjiroTrainingState(TypedDict):
    chieu_thuc: str          # code / chiêu đánh hiện tại
    loi_sai: Optional[str]   # error - vì sao lần trước trật
    so_lan_luyen: int        # attempts
    gioi_han_urokodaki: int  # max_attempts
    thanh_cong: bool


# Node 1: Tanjiro tự luyện / tự sửa chiêu thức (= generate/fix code)
def luyen_chieu(state: TanjiroTrainingState) -> dict:
    if state.get("loi_sai") is None:
        # Lần đầu: Tanjiro chém theo bản năng -> thiếu 1 nhịp xoay tay
        chieu = "chem_ngang(luc=5, xoay_co_tay=False)"
    else:
        # Tanjiro ngửi thấy "mùi" thất bại (error message) và tự sửa
        chieu = "chem_ngang(luc=5, xoay_co_tay=True)"
    return {"chieu_thuc": chieu, "so_lan_luyen": state["so_lan_luyen"] + 1}


# Node 2: Zenitsu "kiểm tra" kết quả (= run_tests)
def zenitsu_kiem_tra(state: TanjiroTrainingState) -> dict:
    chieu = state["chieu_thuc"]
    if "xoay_co_tay=True" in chieu:
        return {"loi_sai": None, "thanh_cong": True}
    else:
        return {
            "loi_sai": "Tang da khong vo - thieu nhip xoay co tay luc chem",
            "thanh_cong": False,
        }


# Conditional edge: Urokodaki quyết định bước tiếp theo
def urokodaki_quyet_dinh(state: TanjiroTrainingState) -> str:
    if state["thanh_cong"]:
        return "dat_chung_nhan"      # done -> END
    if state["so_lan_luyen"] >= state["gioi_han_urokodaki"]:
        return "duoi_ve_nui"         # give_up -> END
    return "luyen_lai"               # retry -> quay lại luyen_chieu


graph = StateGraph(TanjiroTrainingState)
graph.add_node("luyen_chieu", luyen_chieu)
graph.add_node("zenitsu_kiem_tra", zenitsu_kiem_tra)

graph.add_edge(START, "luyen_chieu")
graph.add_edge("luyen_chieu", "zenitsu_kiem_tra")
graph.add_conditional_edges(
    "zenitsu_kiem_tra",
    urokodaki_quyet_dinh,
    {
        "dat_chung_nhan": END,
        "duoi_ve_nui": END,
        "luyen_lai": "luyen_chieu",   # <-- CYCLE
    },
)

app = graph.compile()

ket_qua = app.invoke(
    {
        "chieu_thuc": "",
        "loi_sai": None,
        "so_lan_luyen": 0,
        "gioi_han_urokodaki": 3,
        "thanh_cong": False,
    },
    config={"recursion_limit": 20},
)
print("So lan luyen:", ket_qua["so_lan_luyen"])
print("Thanh cong:", ket_qua["thanh_cong"])
print("Chieu thuc cuoi cung:", ket_qua["chieu_thuc"])

Output (thật, đã chạy kiểm chứng)

=== SO TAY LUYEN TAP CUA TANJIRO ===
So lan luyen: 2
Thanh cong: True
Chieu thuc cuoi cung: chem_ngang(luc=5, xoay_co_tay=True)

Tại sao code này chạy được

LangGraph không quan tâm bạn đặt tên state/node là code/error hay chieu_thuc/loi_sai — nó chỉ quan tâm đúng cấu trúc: (1) node trả về dict để merge vào state, (2) hàm điều kiện trả về string literal khớp key trong mapping, và (3) trong mapping có ít nhất 1 key trỏ ngược về node đã tồn tại — đó là thứ tạo ra cycle. Đổi tên biến sang theme Demon Slayer không đổi logic thực thi vì Python/LangGraph vận hành theo thứ tự gọi hàm và cấu trúc dict, không theo ngữ nghĩa tên biến. Đây là lý do ẩn dụ luôn map được 1-1 sang code thật.
